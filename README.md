# Каталог тем KeepShell

Дополнительные темы для приложений на KeepShell. В настройках приложения выберите
«Установить из каталога» или скачайте ZIP из [Releases](https://github.com/TheVSAKeeper/KeepShell.Themes/releases)
и выберите «Установить из ZIP…».

Каталог для приложений доступен по адресу
[themes.json](https://github.com/TheVSAKeeper/KeepShell.Themes/releases/latest/download/themes.json).
В нём указаны версии пакетов, минимальные версии KeepShell и цвета превью.
Каждый архив содержит DLL, манифест формата 2 и его подпись. KeepShell проверяет подпись
и SHA-256 сборки при установке и загрузке.

Minecraft, Escape from Tarkov, Vice City и Sublime упоминаются как источники оформления.
Каталог независим от разработчиков этих продуктов. В пакете Minecraft используется шрифт
Tektur по SIL Open Font License 1.1. Текст лицензии включён в сборку.
